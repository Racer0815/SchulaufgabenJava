# Java Schulprojekte

This repository contains various Java school projects organized by date.

## Overview

A collection of Java programming exercises and projects completed during school coursework. Each package represents work from a specific date and covers different programming concepts.

## Packages

- **[Day06_07_2026](src/main/java/Day06_07_2026/)** - Basic Java classes and object-oriented programming fundamentals
  - `Apfel.java` - Apple class implementation
  - `Birne.java` - Pear class implementation
  - `Hallo.java` - Main class with basic object creation

- **[Day09_06_2026](src/main/java/Day09_06_2026/)** - Interface implementation and inheritance
  - `Animal.java` - Animal interface defining common behaviors
  - `Hund.java` - Dog class implementing Animal interface
  - `Katze.java` - Cat class implementing Animal interface

- **[Day22_06_2026](src/main/java/Day22_06_2026/)** - Vehicle classes with inheritance
  - `Fahrzeug.java` - Base vehicle class with tank capacity
  - `LKW.java` - Truck class extending Fahrzeug
  - `Segelboot.java` - Sailboat class extending Fahrzeug
